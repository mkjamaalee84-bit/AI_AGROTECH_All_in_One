LANGSUNG
Rujukan operasi, bukan arahan dos. Probiotik bermula pada 0: masukkan kadar label produk. Garam dikira hanya bagi peningkatan saliniti yang anda tetapkan. Molases ialah model teori berasaskan makanan; ia tidak mengambil kira karbon sedia ada atau proses nitrifikasi. Sahkan spesies, TAN, alkaliniti, pepejal flok dan kapasiti aerasi sebelum sebarang penambahan.
Lihat formula & andaian

Biomassa = bilangan × berat (g) ÷ 1,000.
FCR = makanan tempoh ÷ (biomassa semasa − biomassa awal). Model ringkas ini tidak melaras ikan mati atau tuaian pertengahan.
Makanan harian = biomassa × kadar makanan ÷ 100.
N terbuang = makanan harian × protein% ÷ 6.25 × N terbuang%.
Molases (kg/hari) = N terbuang × C:N ÷ pecahan karbon.
Probiotik (mL) = isipadu m³ × dos label.
Garam (kg) ≈ isipadu m³ × max(0, sasaran − semasa) ppt.

KAWALAN RUANG KERJA

Tetapan & integrasi

API key dalam pelayar boleh dibaca oleh skrip pada origin ini, sambungan pelayar atau pengguna peranti. localStorage tidak disulitkan. Gunakan key sendiri pada peranti dipercayai; jangan masukkan key dalam GitHub. Untuk penggunaan organisasi, gunakan backend/proksi dengan pengesahan pengguna. Caj & had API pembekal tetap terpakai.

Akaun staf · Firebase syarikat

Konfigurasi yp-agrotech-bioflok telah ditanamkan. Log masuk sekali pada peranti dipercayai; sesi dipulihkan secara automatik apabila aplikasi dibuka semula.

Memulakan sambungan...

Akaun dan keahlian staf diaktifkan oleh pentadbir dalam Firebase Console. Kata laluan tidak disimpan oleh kod aplikasi. Log keluar selepas menggunakan peranti bersama. Chat AI dan key API tidak dikongsi kepada staf lain.

Sandaran & aplikasi

Sandaran peranti merangkumi log lama, chat dan draf; laporan syarikat dieksport berasingan selepas log masuk. Import JSON hanya memulihkan data peranti dan tidak menulis ke koleksi syarikat. API key tidak dieksport.
